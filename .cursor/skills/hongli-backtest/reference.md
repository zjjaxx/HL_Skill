# 策略与回测口径（摘要）

完整原文：`blog/src/post/布林线.md`

## 价格口径

| 用途 | 复权 |
|------|------|
| 布林、%b、周/月位置、站上中轨 | 前复权 |
| 成交价、股息率分母、现金分红入账 | 不复权 |

- BB(20, 2)；%b=(价−下)/(上−下)；带宽=(上−下)/中轨
- RSI 14；MFI 10；均量 20 周（放量 1.5× / 恐慌 2× / 缩量 0.8×）
- 主周期周线；月线定位置；日线优化执行

## 第 0 步硬门槛（须全部满足才可买）

1. 股息率 ≥ 2 × 30 年国债收益率
2. 连续 3 年分红
3. 近 3 年经营现金流合计 ≥ 近 3 年现金分红合计
4. 市值 ≥ 1000 亿

回测简化（原文约定）：样本股上市值/现金流可默认通过；实际硬过滤多为 **股息率×国债 + 连续 3 年分红**。

### 股息率

`完整一年每股股息 / 当日不复权收盘`  
完整一年 = 按上一日历年派息月份模板拼接（今年已派用今年，未派用去年同期；新年份多出的月额外计入）。

## 买卖顺序

0. 硬门槛  
1. 月：收盘 ≤ 上月中轨，且股息历史分位 ≥ 80%（≥5 年样本）  
2. 周：当周 forming（截至当日）%b ≤ 0.25（须买入日仍满足；不用已收完周线延后）  
3. 日：最低价 > 日中轨，且 `0.5 < %b ≤ 0.8`；同月限购 1 次  
4. 持有：不因日线止损，靠股息消化浮亏  
5. 减仓：
   - 周 %b ≥ 1 → 卖 20%（同波段一次）
   - 月 %b ≥ 1 → 卖 30%（同波段一次）
   - 分位从 ≥80 回落到 78/76/74/72/70：每档卖「阶梯首次触发时持仓」的 10%；≤70 清仓

## 多账号滚动

- 每账号初始 100 万；全仓买；独立减仓档；除权日股息入现金
- 空闲账号环形接单；全忙 → `miss_busy`
- 同月限购全局 → `miss_month`（不算账号不足）
- N = 使 `miss_busy=0` 的最小整数
- 资金池收益 = Σ期末权益 / (N×100万) − 1

## 本金浮亏

- 成本 = 买入金额（不复权×股数）
- 路径权益 = 已实现（卖出回笼+股息）+ 余仓×当日不复权收盘
- 本金最大浮亏 = min(权益−成本)
- 价 MAE 不含股息；本金浮亏含股息与减仓回笼
